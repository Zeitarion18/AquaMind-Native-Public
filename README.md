# AquaMind Native 0.7.9 — Smart Reminders 3.1

Версия 0.7.9 (сборка **29**) — надёжность локальных уведомлений и обратный отсчёт, без изменения локального хранилища или идентификатора iPhone-приложения.

- **Обратный отсчёт на главной:** показывает «Через 24 мин» от даты ближайшего **подтверждённого iOS** уведомления. Если очередь не подтверждена, приложение честно показывает лишь расчётное время.
- **Проверка очереди:** Snooze больше не скрывает несовпадение обычных уведомлений; два отложенных запроса распознаются как сбой. Уже сработавшее уведомление не числится ошибочно потерянным.
- **Восстановление одним нажатием:** при несовпадении появился «Восстановить очередь уведомлений», с безопасным пересчётом без очистки дневника, сна, Snooze или пауз.
- **Сон:** можно отметить позднее пробуждение в течение суток после «Лёг спать», даже после автоматического окончания ночной паузы. Нажатие «Проснулся» пересчитывает интервалы от фактического времени.
- **Тесты:** новый набор проверяет обратный отсчёт, ранний и поздний подъём, ночную паузу, защиту Snooze, устранение дублей и расписание после записи напитка.
- **Совместимость:** iOS 17+, прежний Bundle ID `com.aquamind.nativehydration`, та же стеклянная иконка 0.7.8. Собранный без подписи IPA для Sideloadly. Устанавливать **поверх 0.7.8**, не удаляя приложение.

Очередь iOS подтверждает принятие запросов, **но не гарантирует** показ баннера, звук или вибрацию: они зависят от разрешений, фокусирования, сводки и настроек самого iPhone.

# AquaMind Native 0.7.6 — Smart Reminders 3.0

Версия 0.7.6 расширяет локальные уведомления без облачных сервисов, подписок или изменения Bundle ID (`com.aquamind.nativehydration`).

- **Режимы напоминаний:** бережный (первые 2 повтора 60 мин, далее 90), сбалансированный (40/60; соответствует логике 0.7.3–0.7.5) и активный (30/45). Установленная пользователем минимальная пауза всегда имеет приоритет. Интервалы **не** являются рекомендацией выпивать воду по расписанию.
- **Звук или без звука:** настройка для локальных уведомлений; при смене пересоздаются только отличающиеся по звуку запросы. Приложение не может гарантировать вибрацию без звука — это зависит от iOS.
- **Отложить:** настраиваемая кнопка 5/10/15/30/60 минут в уведомлении. Состояние отложенного срока хранится в `hydration.json`. Защитное окно ещё 20 минут после выбранного срока не позволяет старым обычным напоминаниям возникнуть при переоткрытии приложения.
- **Временная пауза:** 30 минут, 1 час, 2 часа, до следующего пробуждения. Сохраняется и автоматически заканчивается по времени. В настройках доступно досрочное возобновление.
- **Дневная цель и сон:** полностью исключают ненужные уведомления. После новой записи о напитке отложенное напоминание сбрасывается, план пересчитывается.
- **Главная карточка:** Smart Hydration 3.0, режим, звук, объяснение и проверка реальной очереди iPhone.
- **Совместимость:** история напитков, все пользовательские напитки и иконки, Aurora Ring 0.7.5, аналитика, недельный сон, действия «Выпил 150/250/350 мл» и Apple Watch Shortcuts сохраняются без миграции данных.

**Сборка:** GitHub Actions → Build AquaMind Native 0.7.6 iPhone IPA → Run workflow. Стандартный неподписанный IPA для Sideloadly без WidgetKit. Устанавливай поверх 0.7.5 и **не удаляй приложение**, чтобы не потерять локальный дневник.

# AquaMind Native

Личное iOS-приложение для учёта выпитой жидкости. SwiftUI, iOS 17+, без подписок и обязательного аккаунта.

**Текущая версия:** 0.7.5 — Aurora Bubble Mask Fix.

## Приватность

В этом репозитории находятся **исходный код и ресурсы приложения**, но **нет личной истории напитков пользователя**. Дневник жидкости сохраняется в контейнере приложения на устройстве (`Application Support/AquaMind/hydration.json`).

> Репозиторий публичный. Никогда не добавляйте сюда пароли, токены, сертификаты подписи, `.env` или личные файлы.

## Сборка IPA для Sideloadly

1. Откройте вкладку **Actions** и выберите **Build AquaMind Native iPhone IPA**.
2. Нажмите **Run workflow** на ветке `main`.
3. После успешного выполнения скачайте артефакт `AquaMind-Native-0.7.5-Standard-IPA` и извлеките `.ipa` из ZIP.
4. Устанавливайте поверх предыдущей версии с тем же `com.aquamind.nativehydration` через Sideloadly, **не удаляя приложение**.

Сборка использует стандартный GitHub-hosted macOS runner, XcodeGen и Xcode, без WidgetKit-расширения. Сборка неподписанная; Sideloadly выполняет подпись при установке.

**Важно:** GitHub Actions запускается **только вручную**, чтобы не собирать IPA при каждом коммите.

## Внутри

- Учёт воды и других напитков, пользовательские напитки и быстрые объёмы.
- Aurora Ring с цветными дугами, скруглениями, мягким свечением и маскированными живыми пузырьками.
- Локальная история, статистика Swift Charts.
- Smart Hydration 2.0: адаптивные напоминания и недельный график сна.
- Действия «Команд» для добавления воды с iPhone и Apple Watch.

## Разработка

Основной проект: `project.yml`, XcodeGen; UI: `AquaMind/Views`; расчёты: `AquaMind/Core`. Тесты в `Tests` запускаются workflow перед сборкой IPA.

Этот репозиторий создан из актуальных исходников без импорта приватной истории коммитов.
