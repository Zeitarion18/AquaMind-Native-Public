# AquaMind Native

Личное iOS-приложение для учёта выпитой жидкости. SwiftUI, iOS 17+, без подписок и обязательного аккаунта.

**Текущая версия:** 0.7.5 — Aurora Bubble Mask Fix.

## Приватность

В этом репозитории находятся **исходный код и ресурсы приложения**, но **нет личной истории напитков пользователя**. Дневник жидкости сохраняется в контейнере приложения на устройстве (`Application Support/AquaMind/hydration.json`).

> Репозиторий публичный. Никогда не добавляйте сюда пароли, токены, сертификаты подписи, `.env` или личные файлы.

## Сборка IPA для Sideloadly

1. Откройте вкладку **Actions** и выберите **Build AquaMind Native iPhone IPA**.
2. Нажмите **Run workflow** на ветке `main`.
3. После успешного выполнения скачайте артефакт `AquaMind-Native-0.7.5-Standard-IPA` и извлеките `.ipa` из ZIP.
4. Устанавливайте поверх предыдущей версии с тем же `com.aquamind.nativehydration` через Sideloadly, **не удаляя приложение**.

Сборка использует стандартный GitHub-hosted macOS runner, XcodeGen и Xcode, без WidgetKit-расширения. Сборка неподписанная; Sideloadly выполняет подпись при установке.

**Важно:** GitHub Actions запускается **только вручную**, чтобы не собирать IPA при каждом коммите.

## Внутри

- Учёт воды и других напитков, пользовательские напитки и быстрые объёмы.
- Aurora Ring с цветными дугами, скруглениями, мягким свечением и маскированными живыми пузырьками.
- Локальная история, статистика Swift Charts.
- Smart Hydration 2.0: адаптивные напоминания и недельный график сна.
- Действия «Команд» для добавления воды с iPhone и Apple Watch.

## Разработка

Основной проект: `project.yml`, XcodeGen; UI: `AquaMind/Views`; расчёты: `AquaMind/Core`. Тесты в `Tests` запускаются workflow перед сборкой IPA.

Этот репозиторий создан из актуальных исходников без импорта приватной истории коммитов.
